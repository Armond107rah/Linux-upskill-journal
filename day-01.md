# Day 01 - Get to know your Server

The objective of Day 01 is to become familiar with my Linux server environment and learn how to inspect basic system information from the command line.

For this challenge, I am using a DigitalOcean cloud server running Ubuntu Linux.

The exercises cover identifying the current user, Linux distribution, system uptime, kernel, active users, CPU resources, storage, memory, filesystem capacity, and networking.

---

## Lab Environment

For the Linux Upskill Challenge, I created a Linux server using DigitalOcean.

- **Cloud Provider:** DigitalOcean
- **Operating System:** Ubuntu 24.04.5 LTS
- **Release:** 24.04
- **Codename:** Noble Numbat
- **Remote Access:** SSH
- **Shell:** Bash
- **Current User:** root
- **Hostname:** `ubuntu-s-1vcpu-512mb-10gb-sfo2`

This DigitalOcean server will serve as my Linux lab environment throughout the challenge.
