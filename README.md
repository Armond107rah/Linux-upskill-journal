## Commands I Learned or Relearned Today

| Command | What It Does |
|---|---|
| `whoami` | Shows the currently logged-in user |
| `uptime` | Shows how long the Linux server has been running |
| `pwd` | Shows the current directory |
| `ls` | Lists files and directories |
| `sudo` | Runs a command with elevated privileges |
| `apt update` | Refreshes Ubuntu's package information |
| `apt upgrade` | Installs available package updates |
